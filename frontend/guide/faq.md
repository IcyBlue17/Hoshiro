# 常见问题

## 按 Fn 键弹出系统表情面板或切换输入法

打开 macOS「系统设置 › 键盘」，将「按下 🌐 键时」选项调整为 **「不执行任何操作」**。

## 按住快捷键无响应

1. 检查「设置 › 权限」中 **麦克风、辅助功能、输入监控** 三项系统权限是否均已获得授权。
2. 确认未同时运行 Typeless（两者均通过底层的系统事件钩子监听按键，同时运行会发生冲突）。
3. 检查系统菜单栏是否存在 Hoshiro 图标，若不存在请重新启动应用。

## 输入完成后未插入文字，弹出「复制」提示

当前输入焦点未处于可编辑的文本框内。可点击目标输入框获取光标后再试；亦可直接点击提示卡片上的「复制」按钮，或使用快捷键 <Kbd size="sm">Ctrl</Kbd> + <Kbd size="sm">⌘</Kbd> + <Kbd size="sm">V</Kbd> 手动粘贴。

## 提示「改写失败，已插入原始转录」

改写服务请求失败。常见原因包括：API Key 填写错误、账户额度耗尽、选定的模型名称不存在或无访问权限。请前往「设置 › 模型服务」点击「测试连接」查看具体的错误返回码及响应信息。

## 输入整体延迟较高

请前往「使用统计 › 速度」查验各阶段耗时分布，具体分析建议参见 [性能排查](./statistics#速度分析与性能排查)。

## 系统钥匙串授权提示频繁弹出

系统弹出「Hoshiro 想要使用钥匙串中的机密信息」授权对话框时，请选择 **「始终允许」**。当应用进行版本更新且签名发生变化时，系统可能会重新请求确认一次。

## 打开时提示应用“已损坏”

在终端中执行以下命令清除文件隔离标志：

```bash
xattr -cr /Applications/Hoshiro.app
```

## 是否支持 Windows 或 Linux 平台？

目前处于开发适配阶段，代码库已预留跨平台架构，现阶段优先保障 macOS 平台的完整体验。
