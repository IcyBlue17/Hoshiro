# 个性化与词典

相关配置位于「设置 › 个性化」及侧边栏的「词典」模块。

## 文本处理偏好

| 选项 | 作用 |
|---|---|
| **智能格式化** | 将口述中的枚举序数转换为结构化列表；规范邮箱、URL 等书面格式 |
| **长段整理** | 「分段」按语义自动划分段落；「列点」整理为编号列表 |
| **自动添加词典** | 手动修改刚插入的文字后，系统自动将修正词记录至本地词典 |
| **个性化学习** | 定期在本地分析历史记录，提取个人常用专有名词、口癖与修改偏好 |
| **自定义指令** | 向改写大模型注入额外 Prompt 约束 |

### 自定义指令示例

```text
语气保持商务正式，称呼使用“您”。
技术名词保持英文原样，不要翻译。
不要使用感叹号。
```

## 个性化学习

开启「AI 个性化学习」后，系统将在本地定期分析历史输入数据，自适应提取：

- 高频提及的专有名词（人名、项目名、产品术语）
- 个人口头语与特定停顿习惯
- 手动修改历史中的纠偏规则

学习产物展示于「已学会」列表中，支持逐条查阅或手动移除。学习过程中的模型调用仅发往配置的改写模型端点。

## 专有名词词典

在侧边栏「词典」界面维护专属词汇库：人名、公司名称、项目代号、专业术语等。词典中的条目会作为提示词优先参与改写纠错，有效降低 ASR 同音字误识别率（如将“陶瑞”纠偏为“Tauri”）。

### 批量导入

支持导入 **单列 CSV** 格式文件，每行包含一个词汇条目：

```csv
Hoshiro
Tauri
TestFlight
张子涵
Kubernetes
```

在「词典」页点击导入按钮即可完成加载。
