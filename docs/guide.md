## 基本用法

### 四种模式

| 模式 | 操作 | 结果 |
|---|---|---|
| 口述 | 按住 `Fn` 说话，松开 | 整理后的文字插入光标处 |
| 免提 | 双击 `Fn` 开始，再按 `Fn` 结束 | 同上，适合长段 |
| 翻译 | `Fn` + `Left Shift` 开始，按 `Fn` 结束 | 翻译成目标语言后插入 |
| 随便问 | `Fn` + `Space` 开始，按 `Fn` 结束 | 有选中文字：按你的要求改写并替换；没有：在悬浮条上显示回答 |

录音或处理时按 `Esc` 取消，几秒内可以点「撤销」恢复。只轻点一下 `Fn` 不会录音，只会提示按住说话。

`Ctrl` + `⌘` + `V` 再贴一次上一条结果。

### 悬浮条

- 波形跳动：正在收音。
- 免提模式：左边取消，右边完成。
- 扫光动画：正在识别和整理。
- 出错时上方会弹出提示卡片，带「重试」「复制」等按钮。

不录音时也想显示待机条，打开「设置 › 常规 › 在桌面上显示悬浮条」。点待机条会开始免提录音。

### 快捷键

在「设置 › 快捷键」里修改，一个功能可以绑多个键，比如 `Fn` 和右 `Option` 都能口述。支持单独的修饰键（`Fn`、右 `Option`、右 `⌘` 等）、组合键和鼠标侧键。

## 配置服务商

在「设置 › 模型服务」里配置。语音识别和 AI 改写分开选。每项都有「测试连接」，会产生极少量用量。

### 语音识别

| 服务商 | 需要填写 | 说明 |
|---|---|---|
| 小米 MiMo（推荐） | API Key，区域选「Global」或「中国」 | 中文效果和速度最好，自带标点。模型 `mimo-v2.5-asr` |
| Cloudflare Workers AI | 账户 ID、API Token（需 Workers AI 权限） | 选「Whisper Large v3 Turbo」。服务端排队，通常 2~3 秒 |
| Azure Speech | Speech Key、区域（如 `eastasia`） | 流式，边说边传 |
| Google Cloud Speech | 项目 ID、区域、模型；API Key 或服务账户 JSON 二选一 | 流式，项目需开通 Speech-to-Text |

Cloudflare 的「Whisper 旧版」偶尔输出繁体，「Deepgram Nova-3」只支持英文。

### AI 改写

| 服务商 | 需要填写 | 说明 |
|---|---|---|
| Google Gemini | API Key([Google AI Studio](https://aistudio.google.com/apikey)) | 默认 `gemini-flash-latest` |
| Anthropic Claude | API Key | 默认 `claude-haiku-5-5`，快且便宜 |
| OpenAI 兼容 | Base URL、API Key、模型名 | OpenAI、OpenRouter、DeepSeek 和各种中转都选这个 |

模型名可以点「获取模型列表」拉取。

以 Vercel AI Gateway 为例：

- 改写服务选「OpenAI 兼容」
- Base URL:`https://ai-gateway.vercel.sh/v1`
- API Key：在 Vercel 控制台 › AI Gateway › API Keys 创建
- 模型名带厂商前缀，如 `google/gemini-2.5-flash-lite`。免费额度不能用所有模型，选到不能用的会提示「拒绝访问」并附原因

想用 Claude 又要最快速度，可以选 Anthropic，Base URL 填 `https://ai-gateway.vercel.sh`（不加 `/v1`）。

### 思考强度

「模型服务 › 改写」里的「思考强度」默认关闭，建议保持。开启后模型会先思考再改写，长段可能慢好几倍，效果提升不大。

## 个性化

在「设置 › 个性化」：

- 智能格式化：口述的列举自动变成列表，邮箱、网址写成书面形式。
- 长段整理：「分段」按话题分段，尽量保留原话；「列点」把连着说的几件事整理成 1. 2. 3.。
- 自动添加到词典：插入后你手动改了某个词，会把改后的写法记进词典。
- AI 个性化学习：定期分析历史，学习常用词、口癖和常见纠错。结果列在「已学会」里，点 × 删除。「高级」里可以单独指定模型。
- 自定义指令：给改写模型加自己的要求，比如“称呼对方为‘您’”。

「词典」页可以手动添加人名、产品名、术语，也能导入单列 CSV。词典里的写法优先使用，专有名词老识别错时很有用。

## 数据与隐私

- 历史记录、录音、词典、统计只存在本机：`~/Library/Application Support/cn.icybit.hoshiro/`
- API Key 存在 macOS 钥匙串（条目 `cn.icybit.hoshiro`），设置文件里没有明文。
- 音频和文字只会发给你配置的语音识别和改写服务商。
- 「历史记录」页可设置保留时长（从不 / 24 小时 / 1 周 / 1 个月 / 1 年 / 永远），过期的记录和录音自动删除。
- 日志在数据目录的 `logs/`，只记录耗时和字数，不含内容。

## 常见问题

**按 Fn 弹出表情面板或听写**
把「系统设置 › 键盘 › 按下 🌐 键时」改成「不执行任何操作」。

**按住 Fn 没反应**
1. 检查「设置 › 权限」里三个权限是否都已授权，授权后不用重启。
2. Typeless 是否还开着。两个应用会抢 Fn 键，首页会提示并可一键退出。
3. 菜单栏有没有 Hoshiro 图标，没有就重新打开应用。

**说完没插入，弹出了「复制」**
当前焦点不在可输入的位置。点一下输入框再试，或直接点「复制」。

**提示「改写失败，已插入原始转录」**
改写服务出错，提示里有原因，常见的是 Key 无效、余额不足、模型无权限。到「模型服务」检查并点「测试连接」。

**识别慢**
在「使用统计 › 速度」看时间花在哪。Cloudflare 慢主要是服务端排队；中文建议用 MiMo，短句通常不到 1 秒。改写慢的话，确认思考强度是「关闭」，再换个快的模型。

**输出繁体字**
Cloudflare 的「Whisper 旧版」偶尔这样。换成「Whisper Large v3 Turbo」，或开启 AI 改写，它会按语言设置转成简体。

**弹出「Hoshiro 想要使用钥匙串中的机密信息」**
点「始终允许」。更新到签名不同的版本后可能再问一次。

**卸载**
删除 `/Applications/Hoshiro.app` 和 `~/Library/Application Support/cn.icybit.hoshiro/`，再在「钥匙串访问」里删掉 `cn.icybit.hoshiro` 条目。
