## 基本用法

### 四种模式

| 模式 | 怎么用 | 结果 |
|---|---|---|
| 口述 | 按住 `Fn` 说话，松开 | 整理好的文字插入光标处 |
| 免提 | 双击 `Fn` 开始，再按一次 `Fn` 结束 | 同上，适合长段 |
| 翻译 | `Fn` + `Left Shift` 开始，按 `Fn` 结束 | 翻译成你设定的目标语言后插入 |
| 随便问 | `Fn` + `Space` 开始，按 `Fn` 结束 | 选中了文字：按你的要求改写并替换；没选：在悬浮条上显示回答 |

录音或处理过程中按 `Esc` 取消，几秒内可以点「撤销」恢复。只是轻点一下 `Fn` 不会开始录音，会提示你按住说话。

`Ctrl` + `⌘` + `V` 会把上一条结果再贴一次。

### 悬浮条

录音时屏幕底部会出现一条黑色胶囊：

- 波形在跳，说明正在收音；
- 免提模式下左边是取消、右边是完成；
- 出现扫光动画，说明在识别和整理；
- 出错时上方会弹出提示卡片，比如「重试」「复制」。

想在不录音时也看到一个小待机条，可以打开「设置 › 常规 › 在桌面上显示悬浮条」，点一下待机条就能开始免提录音。

### 快捷键

「设置 › 快捷键」里每个功能都能改，也能绑多个键，比如同时用 `Fn` 和右 `Option` 口述。支持单独的修饰键（`Fn`、右 `Option`、右 `⌘`……）、组合键，以及鼠标侧键。

## 配置服务商

在「设置 › 模型服务」里配置。语音识别和 AI 改写分开选，每家都有「测试连接」按钮，测试会产生极少量用量。

### 语音识别

| 服务商 | 需要填写 | 说明 |
|---|---|---|
| **小米 MiMo**（推荐） | API Key；区域选「Global」或「中国」 | 中文效果和速度最好，自带标点。模型 `mimo-v2.5-asr` |
| **Cloudflare Workers AI** | 账户 ID、API Token（需要 Workers AI 权限） | 选「Whisper Large v3 Turbo」。服务器排队，通常 2～3 秒 |
| **Azure Speech** | Speech Key、区域（如 `eastasia`、`japaneast`） | 流式识别，边说边传 |
| **Google Cloud Speech** | 项目 ID、区域、模型；API Key 或服务账户 JSON 二选一 | 流式识别，项目需要开通 Speech-to-Text |

Cloudflare 里的「Whisper 旧版」偶尔会输出繁体，「Deepgram Nova-3」只支持英文。

### AI 改写

| 服务商 | 需要填写 | 说明 |
|---|---|---|
| **Google Gemini** | API Key（[Google AI Studio](https://aistudio.google.com/apikey)） | 默认模型 `gemini-flash-latest` |
| **Anthropic Claude** | API Key | 默认 `claude-haiku-5-5`，快且便宜 |
| **OpenAI 兼容** | Base URL、API Key、模型名 | OpenAI、OpenRouter、DeepSeek、各种中转都走这里 |

模型名可以点「获取模型列表」从服务商那里拉取。

**例：Vercel AI Gateway**

- 「改写服务」选 **OpenAI 兼容**
- Base URL：`https://ai-gateway.vercel.sh/v1`
- API Key：Vercel 控制台 › AI Gateway › API Keys 里创建的 Key
- 模型：带厂商前缀，比如 `google/gemini-2.5-flash-lite`。注意免费额度不能用所有模型，选了用不了的模型会提示「拒绝访问」并附上原因

想用 Claude 并保持最快速度，也可以选 **Anthropic**，Base URL 填 `https://ai-gateway.vercel.sh`（不加 `/v1`）。

### 思考强度

「模型服务 › 改写」里的「思考强度」默认是 **关闭**，推荐保持关闭。开启后模型会先思考再改写，长段可能慢好几倍，效果提升有限。

## 让结果更合心意

在「设置 › 个性化」里：

- **智能格式化**：口述的列举自动变列表，邮箱、网址写成书面形式。
- **长段整理**：「分段」按话题分段、尽量保留原话；「列点」把连着说的几件事整理成 1. 2. 3.，更像 Typeless。
- **自动添加到词典**：插入后你手动改掉某个词，Hoshiro 会把改后的写法记进词典。
- **AI 个性化学习**：定期分析你的历史，学会常用词、口癖和常见纠错。学到的东西都列在「已学会」里，点 × 就能删。「高级」里可以给它单独指定模型。
- **自定义指令**：给改写模型加你自己的要求，比如「称呼对方为‘您’」。

**词典** 页可以手动添加人名、产品名、术语，也能导入一列的 CSV。词典里的写法会优先使用，专有名词总被识别错时最管用。

## 数据与隐私

- 历史记录、录音、词典、统计都只存在这台 Mac 上：`~/Library/Application Support/cn.icybit.hoshiro/`
- API Key 存在 macOS 钥匙串（条目名 `cn.icybit.hoshiro`），设置文件里不保存明文。
- 音频和文字只会发给你自己配置的语音识别和改写服务商。
- 「历史记录」页可以设置保留多久（从不 / 24 小时 / 1 周 / 1 个月 / 1 年 / 永远），过期的记录和录音会自动删除。
- 日志在数据目录的 `logs/` 里，只记录耗时和字数，不记录你说的内容。

## 常见问题

**按 Fn 弹出了表情面板 / 听写**
把「系统设置 › 键盘 › 按下 🌐 键时」改成「不执行任何操作」。

**按住 Fn 没反应**
1. 「设置 › 权限」里三个权限是否都已授权。授权后不需要重启。
2. Typeless 是不是还开着？两个应用会抢 Fn 键，首页会提示并提供一键退出。
3. 菜单栏有没有 Hoshiro 的图标。没有的话重新打开应用。

**说完没插入文字，而是弹出「复制」**
当前焦点不在可输入的位置。点一下输入框再试，或者直接点「复制」。

**提示「改写失败，已插入原始转录」**
改写服务出错了，提示里会写原因：Key 无效、余额不足、模型无权使用等。按原因去「模型服务」检查，点「测试连接」确认。

**识别慢**
看「使用统计 › 速度」能知道时间花在哪。Cloudflare 主要是服务器排队；中文推荐 MiMo，短句通常不到 1 秒出结果。改写慢的话，确认思考强度是「关闭」，并选一个快的模型。

**出来的是繁体字**
Cloudflare 的「Whisper 旧版」偶尔会输出繁体，换成「Whisper Large v3 Turbo」；或者开着 AI 改写，它会按你的语言设置转成简体。

**弹出「Hoshiro 想要使用钥匙串中的机密信息」**
点「始终允许」。更新到签名不同的版本后可能会再问一次。

**怎么彻底卸载**
删掉 `/Applications/Hoshiro.app` 和 `~/Library/Application Support/cn.icybit.hoshiro/`，再在「钥匙串访问」里删除 `cn.icybit.hoshiro` 条目。
